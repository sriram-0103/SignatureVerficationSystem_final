# Signature Verification System

## Overview

Signature Verification System is an AI-powered forensic application that verifies handwritten signatures using Machine Learning, Feature Extraction, Similarity Analysis, and Pseudo-Temporal Stroke Analysis.

The system captures three reference signatures during enrollment and compares a newly submitted signature against the stored biometric template to determine whether it is authentic or forged.

---

## Features

- Customer Registration
- Three Signature Enrollment
- Mobile Signature Capture
- QR Code Connection
- AI-based Signature Verification
- Similarity Analysis
- Human Verification Decision Logic
- Verification History
- Dashboard Analytics
- Automatic PDF Report Generation
